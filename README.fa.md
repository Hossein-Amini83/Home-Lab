# Write-up های آزمایشگاه شخصی تست نفوذ

تمرین‌های عملی تست نفوذ و Red Team و Write-up های مربوط به آن‌ها، از آزمایشگاه شخصی من — مستندسازی مسیر پیشرفت از صفر تا سطح حرفه‌ای.

🇬🇧 [English Version](README.md)

## درباره این Repo

این مخزن یک لاگ پیوسته از تمرین‌های عملی تست نفوذ است که در یک آزمایشگاه ایزوله و شخصی انجام می‌دهم، همراه با یک Write-up ساختاریافته برای هر تمرین. هدف، ساختن مهارت واقعی و قابل اثبات در امنیت شبکه و Red Team است، تمرین به تمرین.

## محیط آزمایشگاه

- **ماشین مهاجم:** Kali Linux
- **ماشین‌های هدف:**
  - Metasploitable 2 (لینوکس)
  - Windows Server 2025 (Server Core)
  - Windows 10
- **شبکه:** Host-only و کاملاً ایزوله (`192.168.56.0/24`)

تمام تست‌ها فقط روی ماشین‌هایی انجام می‌شود که متعلق به خودم هستند، در یک شبکه ایزوله و بدون دسترسی اینترنتی.

## مهارت‌ها / ابزارهای فعلی

- لینوکس (کاربر روزمره)
- شبکه مقدماتی (آدرس‌دهی IP، Subnetting، پروتکل‌های پایه)
- Nmap
- Wireshark
- John the Ripper
- Hydra

*(هر بار که مهارت یا ابزار جدیدی یاد گرفتم، این لیست به‌روز می‌شود.)*
